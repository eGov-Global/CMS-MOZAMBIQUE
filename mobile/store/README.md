# Google Play store listing

Portuguese (`pt-PT`) listing for **Fala Cidadão** (`mz.gov.falacidadao`), in
the folder layout fastlane `supply` reads (`<locale>/title.txt`,
`short_description.txt`, `full_description.txt`, `images/`), so it can be
uploaded by hand in Play Console today and by tooling later.

| File | Play Console field | Limit |
|---|---|---|
| `pt-PT/title.txt` | App name | 30 characters |
| `pt-PT/short_description.txt` | Short description | 80 characters |
| `pt-PT/full_description.txt` | Full description | 4000 characters |
| `pt-PT/images/icon.png` | App icon | 512×512 PNG |
| `pt-PT/images/featureGraphic.png` | Feature graphic | 1024×500 |
| `pt-PT/images/phoneScreenshots/*.png` | Phone screenshots | 2–8, 1080×1920 here |

The texts are drafts for IGE to approve. The icon and feature graphic use the
national emblem, as falacidadao.gov.mz does; the screenshots are the site's
landing page at phone size. Replace them with in-app screens (filing a
complaint, the timeline, the receipt) once a reviewer account exists.
